# Personal Portfolio Website

This project is my personal portfolio website created to showcase my projects, skills, and web development journey. It highlights my frontend development work with a clean, modern, and responsive design.

# Technologies Used
- HTML
- Tailwind CSS
- JavaScript
- Static Website Files (No backend)

# Features
- Responsive and modern user interface
- Project showcase section
- Skills and technologies display
- Smooth animations and transitions
- Interactive navigation
- Contact section

# Sections Included
- Home
- About Me
- Skills
- Projects
- Contact

# Live Website
https://myptfoliowebsite.netlify.app/

# How to Run
1. Clone the repository:
   git clone https://github.com/lakshminarayanverma91-bot/portfolio-website

2. Open the project folder:
   cd portfolio-website

3. Open index.html in your browser
