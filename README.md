## ⚙️ How to Run

1. Clone the repository:

   ```
   git clone https://github.com/lakshminarayanverma91-bot/portfolio-website
   ```

2. Open the project folder:

   ```
   cd portfolio-website
   ```

3. Open `index.html` in your browser
